product-db-1         db        Up (healthy)
product-cache-1      cache     Up (healthy)
product-backend-1    backend   Up
product-nginx-1      nginx     Up


Dlatego dla produkcji bez override trzeba uruchamiać:

    docker compose -f compose.yml up -d

A dla developmentu:
    docker compose up -d
albo jawnie:
    docker compose -f compose.yml -f compose.override.yml up -d

Produkcja vs development

Bez override:

docker compose -f compose.yaml config | grep -A5 volumes

Brak bind mountu ./backend:/app.

Z override:

docker compose -f compose.yaml -f compose.override.yaml config | grep -A5 volumes

Widoczne:

volumes:
  - type: bind
    source: ./backend
    target: /app
